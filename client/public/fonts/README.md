# IAMET local fonts

Inter and Oxanium variable fonts, normal style, Latin subset (including Spanish
accented characters). These replace the same fonts previously requested from
Google Fonts; no new typeface is introduced. No italic files are required by the
site's previous Google Fonts request either.

Source: Fontsource Variable packages from the npm registry, version 5.3.0:
- https://www.npmjs.com/package/@fontsource-variable/inter
- https://www.npmjs.com/package/@fontsource-variable/oxanium

Original projects:
- https://github.com/rsms/inter
- https://github.com/sevmeyer/oxanium

The unmodified fonts are distributed under the SIL Open Font License 1.1.
Their respective license texts are included as inter-LICENSE.txt and
oxanium-LICENSE.txt. Font files are served by the IAMET origin and never contain
account data or runtime secrets.
