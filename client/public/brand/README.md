# IAMET approved identity

Approved design: solid DevOps cycle with a central I, original path-drawn IAMET
lettering, and INTEGRACIÓN TECNOLÓGICA. No octagonal/woven exploration is used.

- React: IametTechLogoV2, paths in shared/iamet-brand.ts. The existing drawing,
  glint and wordmark intro animations remain supported. Masks use per-instance IDs.
- SVG: iamet-logo-on-light, iamet-logo-white, iamet-logo-black.
- SVG/PNG with descriptor: iamet-lockup-on-light, iamet-lockup-white,
  iamet-lockup-black. Descriptor size follows the approved 60% enlargement.
- iamet-logo-email.png uses the white lockup for the dark email headers.
- iamet-favicon-devops.svg and PNG, iamet-apple-touch-devops.png, iamet-symbol.svg.
- iamet-social-devops.png supplies Open Graph and Twitter previews.
- Legacy iamet-procesador-*.svg URLs serve the approved DevOps identity for
  backwards compatibility. These names no longer describe the graphic.

Banner embroidery was updated with the built-in imagegen editor. Edit brief:
replace IAMET processor embroidery with the approved solid loop/I and original
wordmark, preserve scene, people, equipment and manufacturer labels, match fabric
perspective, omit the descriptor on small uniform patches. The six active images
are the *-devops.webp files in images/solutions. Original source banners remain
as unused source assets. The RFID reader's original Zebra marking was preserved
in a targeted follow-up edit. PNG outputs were encoded to WebP at quality 90,
without changing dimensions, for delivery.
